# 拾语角色卡与世界书功能说明

## 角色卡

角色卡描述角色本身，包括：

- 姓名与一句话介绍；
- 身份、背景和当前处境；
- 性格、说话方式和与用户的关系；
- 外貌与生图提示词；
- 开场白、当前情境和人物动机；
- 知识边界与禁止知识；
- 正式固定事实；
- 世界书；
- 示例对话和目标。

生成结果先进入编辑页，不会自动保存。用户可以修改全部字段，并决定是否保存。

## 正式固定事实

正式固定事实是作者确认的角色稳定信息，例如：

- 职业；
- 出生地；
- 长期关系；
- 已经发生的重要经历；
- 稳定目标。

状态为 `confirmed` 的事实可以进入 Prompt；状态为 `proposal` 的内容只作为编辑建议，
不会作为正式设定注入。

## 世界书

世界书描述角色所处的世界，例如：

- 世界规则与时代背景；
- 地点；
- 门派、组织或势力；
- 历史与秘密；
- 角色通常知道的世界信息。

世界书不是聊天记忆，也不是角色已经经历过的所有事情。条目按关键词命中进入聊天上下文。
角色档案编辑页可以查看世界书条目，并通过高级 JSON 编辑完整数据。

## 两者区别

| 内容 | 正式固定事实 | 世界书 |
| --- | --- | --- |
| 描述对象 | 角色自身 | 角色所处世界 |
| 示例 | 角色是医生 | 医院属于某组织 |
| 是否必须确认 | 是 | 由作者编辑后保存 |
| 进入 Prompt 的方式 | confirmed 事实注入 | 关键词命中注入 |
| 是否属于聊天记忆 | 否 | 否 |

## 数据安全

- 角色与世界书保存在本机数据库；
- 删除角色会同时删除其世界书和聊天派生数据；
- 备份会包含角色和世界书，但不包含 API Key 或模型权重。
