## 具体改动

### 默认角色与历史数据

PC 产品目录不再返回内置角色。旧角色仍留在内部兼容注册表中，仅为历史 API 与旧测试读取；它们不会显示，也不会在新建产品里生成。清理脚本默认 dry-run，实际删除必须显式确认。

Android 的启动初始化不再播种默认角色。升级时 `ensureDefaults()` 会删除四个旧默认角色，并级联清除：

- 消息；
- 旧记忆与结构化记忆；
- 记忆任务、墓碑、别名、游标和预算；
- 内部状态与状态变化；
- Trace；
- 头像与生成头像文件；
- 语音偏好摘要和抑制标记。

本轮 ADB 没有发现已连接设备，因此 0.12.0 APK 只完成自动测试和构建，未在手机上覆盖安装。上一版真机语音、记忆和图片能力结论仍属于各自历史版本。

### 记忆修正闭环

PC 新增以下管理动作：

- 手工修正事实：创建新的 active 版本，旧版本保留历史链。
- 标记错误：保留原记录作为失效证据，防止相同旧消息再次复活该事实。
- 恢复历史值：以历史版本为依据创建新的 active 版本，不原地改写旧行。
- 忘记主题：停用当前关联事实并建立主题抑制规则。
- 撤销主题抑制：显式解除“不再记录这一主题”的限制。
- 审计与乐观并发：每次编辑、错误标记和恢复都写入管理事件，并使用 `expected_updated_at` 防止覆盖较新的记录。

这解决的是“机器自动记错后，用户只能旁敲侧击纠正”的问题。普通聊天仍不需要逐条确认记忆。

### 自然对话记忆评测

私有 v5 数据集包含 18 个案例、448 轮消息和 90 个探针：

- 1 个来自现有聊天的自动脱敏案例；
- 17 个明确标注的 curated synthetic 案例；
- 覆盖信息提取、事实更新、时间推理、多会话、角色隔离、共同经历、拒绝编造、隐私删除和省略指代。

此前 v1 的测试夹具错误和多轮失败目录均未覆盖；最终 v3 是新的冻结回放。`facts_only` 等模式达到 90/90，说明在当前夹具上，事实存储、版本状态、历史值选择、禁用值和角色隔离能够被检索逻辑正确处理。

不能把 90/90 解释为端到端对话准确率，因为 golden replay 不运行：

- 真实模型的候选提取；
- 语义审核模型；
- 最终回答生成；
- 前端呈现与人工可读性。

### 内部状态消融

评测固定同一完整角色“沈知遥”、同一历史和长期记忆、同一模型、温度、Top-p 和 seed；唯一变化是提示词中是否加入内部心情、熟悉度、信任、温暖、关系阶段和边界。12 个场景覆盖共享好消息、低落、边界、冲突修复、熟悉关系、工作情境、玩笑、隐私和中性控制。

自动结构结果为：

| 条件 | 回答数 | 错误 | 平均字符数 | 显式数值泄漏 | 多问句回答 |
|---|---:|---:|---:|---:|---:|
| 状态关闭 | 12 | 0 | 67.00 | 0 | 0 |
| 状态开启 | 12 | 0 | 80.83 | 0 | 0 |

状态开启输入多 1,011 Token，输出多 96 Token；这既不能证明质量更好，也不能证明关闭更自然。第一次请求因 OpenCode Go 要求 `x-opencode-session` 返回 HTTP 400，该无效运行完整保留在 `results-request-contract-failure.json`。修复后每个条件使用独立、一次性的 OpenCode session，避免一侧看到另一侧回答。

## 原方案与改进后的比较

| 原方案 | 本轮改进 | 当前判断 |
|---|---|---|
| 记忆错误只能查看和删除 | 增加编辑、错误标记、历史恢复、主题抑制和审计 | 有明确收益：修复了“只能靠继续聊天间接纠正”的产品缺口 |
| 旧对话和结构化事实可能重复 | 统一事实、摘要和旧原话的检索预算；宽泛回忆与省略指代扩展 | 在本私有夹具上有效，事实模式 90/90；真实抽取仍待验证 |
| 内部状态只做实现，没有产品收益证据 | 固定 seed 的 12 对真实匿名 A/B | 有明确初步收益：作者总体偏好 6:2，自然度 5:2；仍属单评审证据 |
| 默认角色字段不完整，却被当作主评测对象 | 产品删除默认角色；质量评测改用完整虚构角色 | 有效：减少“角色卡不完整却归因于模型”的混淆 |
| 只有本机开发环境运行经验 | 独立 Conda 前缀环境、独立数据库、真实 API 首聊 | 有明确收益：Windows 云端主链已可复现 |
| 只报告通过项 | 保留无效请求、早期失败回放和限制说明 | 有效：结论可按证据边界复核 |

## 作者评审结论

作者已完成 12 对评分并揭盲。有状态版总体胜出 6 次、无状态版胜出 2 次、4 次平局；自然度为 5:2，情绪延续和关系一致性均未被无状态版胜过。当前 PC 继续默认启用内部状态提示，并保留显式 A/B 配置供后续复验。

## 当前限制

- 自然记忆 90/90 是固定夹具上的存储与检索结果，不是真实模型端到端准确率。
- 状态评测只有 12 对、每侧一次生成、单个作者评审，不能提供统计显著性。
- Android 0.12.0 未做真机覆盖安装；本轮没有连接设备。
- Android 记忆管理没有同步 PC 的完整编辑、错误标记、恢复历史和主题遗忘闭环。
- PC 与 Android 的聊天数据库仍不自动同步。
- GitHub 同步按要求暂停。
