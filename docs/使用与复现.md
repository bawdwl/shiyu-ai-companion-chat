# 使用与复现

本文以当前仓库中的 `0.18.2` 为准，说明 PC 和 Android 的安装、运行与验收。

## 1. 最短 PC 路径：只用云端 API

### 环境

- Windows 10/11
- Python 3.11
- Git

Node.js 和 pnpm 只有修改前端源码时才需要，仓库已包含构建后的
`web/react-dist/`。

### 安装

```powershell
git clone https://github.com/bawdwl/shiyu-ai-companion-chat.git
cd shiyu-ai-companion-chat

conda create -n shiyu-chat python=3.11 pip -y
conda activate shiyu-chat
python -m pip install -r requirements-api-windows-py311.txt
.\scripts\setup_secret_runtime.ps1 -Python python
```

### 启动 OpenCode Go

```powershell
python launch_app.py --provider opencode --speech-provider off --asr-provider off
```

打开 <http://127.0.0.1:8000/ui/>，在设置中填写 OpenCode Go API Key。

### 启动 DeepSeek

```powershell
python launch_app.py --provider deepseek --speech-provider off --asr-provider off
```

打开同一页面，在设置中填写 DeepSeek API Key。两个 Provider 的 Key 分开保存。

## 2. 修改 PC 前端

```powershell
pnpm --dir frontend install --frozen-lockfile
pnpm --dir frontend build
```

构建结果写入 `web/react-dist/`。

## 3. 可选组件

### BGE 语义记忆

```powershell
python -m pip install huggingface_hub
python scripts/fetch_embedding_model.py
```

模型缺失或加载失败时，PC 自动回退到 FTS5 和词法检索。

### PC 语音

PC 语音依赖单独的 Whisper、GPT-SoVITS 或 MeloTTS 模型与服务。模型不随仓库
发布，详见 [语音部署](语音部署.md)。

### 本机 Qwen3

本机模型不是最短复现路径的必要条件。需要时安装完整依赖：

```powershell
python -m pip install -r requirements-lock-windows-py311.txt
python launch_app.py --provider local-base
```

本机权重放在 `outputs/models/qwen3-1.7b/`。LoRA Adapter 和训练资料不包含在
本仓库，相关实验见：
<https://github.com/bawdwl/qwen3-1.7b-lora>

如果只需要 Android 端侧文字模型，可以直接下载公开 MNN Q8 包：

- 宋知意：
  <https://modelscope.cn/models/Alixs666/shiyu-qwen3-1.7b-song-zhiyi-mnn-q8>
- 许澄（实验版）：
  <https://modelscope.cn/models/Alixs666/shiyu-qwen3-1.7b-xu-cheng-mnn-q8>
- 裴既明（实验版）：
  <https://modelscope.cn/models/Alixs666/shiyu-qwen3-1.7b-pei-jiming-mnn-q8>

## 4. Android 源码构建

需要 JDK 17、Android SDK 35 和 Git LFS。

```powershell
$env:JAVA_HOME = "C:\path\to\jdk-17"
$env:ANDROID_HOME = "C:\path\to\Android\Sdk"
.\scripts\build_android.ps1
```

也可以使用 Android Studio 打开 `android/` 并运行 `app`。

输出：

```text
android/app/build/outputs/apk/debug/app-debug.apk
```

可直接从
[GitHub Release](https://github.com/bawdwl/shiyu-ai-companion-chat/releases/tag/v0.18.2)
下载 Android APK，或从源码构建并安装。安装后：

1. 打开“应用设置”。
2. 选择 OpenCode Go 或 DeepSeek并填写自己的 Key。
3. 如需手机离线文字模型，导入 MNN Chat 兼容 ZIP。
4. 如需本地头像，导入 Local Dream SD1.5 QNN ZIP。
5. 如需云端生图，填写单独的千问图片 API Key。
6. 在角色编辑页为每个角色选择云端或本地 MNN。

## 5. 外部模型与许可

以下文件不包含在 Git 仓库：

- Qwen MNN 模型；
- MeinaMix、DreamShaper 等 QNN 生图模型；
- GPT-SoVITS、Whisper、MeloTTS、BGE 权重；
- LoRA Adapter 和原始训练数据。

Local Dream 后端使用 CC BY-NC 4.0，当前项目定位为非商业 Demo。

## 6. 建议验收

1. PC 启动，健康检查成功，首页可打开。
2. 填写对应 Provider Key，创建角色。
3. 发送普通消息，确认流式回答和停止按钮。
4. 告诉角色一条新事实，几轮后追问。
5. 更正同一事实，分别检查“现在”和“历史”值。
6. 删除一条记忆，确认旧原话不会自动复活。
7. 上传一张图片，确认视觉 Provider 能收到图片。
8. 创建第二个角色，确认角色和记忆隔离。
9. Android 填写 Key，重复核心对话流程。
10. 测试麦克风、播放、角色删除、MNN 导入和 Local Dream 导入。

## 7. 常见问题

### PC 启动失败

检查 Python 版本、依赖安装、端口 `8000` 和 `outputs/app-service.log`。

### Provider 鉴权失败

确认 Provider Key 有效、额度充足且当前账号拥有对应模型权限。不要把真实 Key
粘贴到 Issue。

### BGE 不可用

应用会回退到 FTS5。重新运行 `python scripts/fetch_embedding_model.py`。

### Android 没有语音

检查 Git LFS 是否拉取完整、麦克风权限是否允许，以及是否已经选择音色。

### Android 本地模型或生图失败

确认导入的是兼容 ZIP，并检查手机存储空间。MNN 只用于本地文字聊天；
Local Dream 需要兼容的 SD1.5 QNN 模型。

### PC 与 Android 为什么不同步

当前没有账号、中心数据库或跨设备同步。两端各自保存数据。
