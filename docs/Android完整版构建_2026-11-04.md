# Android 单一完整版构建

日期：2026-11-04
版本：`0.17.0 / versionCode 31`

## 安装包

Android 只维护一个完整安装包，包名为 `com.shiyu.chat`。语音输入、角色朗读、
本地 MNN 和图片生成入口全部保留，不再构建带 `.slim` 包名的第二版，也不再
提供应用内 TTS 语音包下载或导入流程。

## 构建命令

```powershell
cd android
.\gradlew.bat testDebugUnitTest assembleDebug lintRelease assembleRelease --no-daemon
```

构建产物：

```text
android/app/build/outputs/apk/debug/app-debug.apk
android/app/build/outputs/apk/release/app-release.apk
```

## 体积说明

完整版会在升级后移除旧 Slim 辅助代码与应用内语音包下载逻辑。当前内置
`sherpa-onnx-vits-zh-ll` 的五个 speaker 去重为四个可用声部，资源约 129 MiB；
旧 Kokoro 资源已移除。
该模型的来源与再分发边界记录在同目录 `MODEL_NOTICE.md`，当前只按非商业
Demo 使用，不能把代码许可证扩大为声音身份或模型权重的商业授权。

Release 关闭 R8 名称压缩，因为 sherpa-onnx 和 MNN 都通过 JNI 固定字段名或
原生方法名加载。混淆版本曾导致 `Failed to get field ID for decodingMethod`
以及本地模型闪退；为保证语音识别、TTS 和 MNN 可用，发布包保留原始 JVM 符号。
