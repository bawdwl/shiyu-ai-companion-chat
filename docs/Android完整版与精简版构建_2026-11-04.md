# Android 完整版与精简版构建

日期：2026-11-04
版本：`0.15.0 / versionCode 28`

## 两个安装包

| 构建 | 包名 | 语音输入 | 角色朗读 |
|---|---|---|---|
| Full | `com.shiyu.chat` | 内置 sherpa-onnx ASR | 内置 Kokoro 103 音色 |
| Slim | `com.shiyu.chat.slim` | 内置 sherpa-onnx ASR | 下载或导入后启用 |

两个 APK 使用不同包名，可以同时安装。语音输入和本地转文字始终保留在
两个版本中，删除 Kokoro 朗读包不会影响语音输入。

## 精简版朗读包

精简版首次安装不包含 `src/full/assets/speech/kokoro`。用户在“设置 → 对话与模型”
中可以选择：

1. 下载 sherpa-onnx 官方 `kokoro-int8-multi-lang-v1_1` 归档；
2. 从手机文件中选择兼容的 ZIP 或 TAR.BZ2。

下载大小约 140 MB，安装后约 200 MB。安装包会校验必需模型、词表、中文规则与
`espeak-ng-data` 目录，拒绝路径越界、链接文件和超过 400 MiB 的解压结果。
安装成功后，103 音色搜索、试听、角色独立音色选择和完整版一致。

## 构建命令

```powershell
cd android
.\gradlew.bat testFullDebugUnitTest testSlimDebugUnitTest `
  assembleFullDebug assembleSlimDebug lintFullRelease lintSlimRelease `
  assembleFullRelease assembleSlimRelease --no-daemon
```

构建产物：

```text
android/app/build/outputs/apk/full/debug/app-full-debug.apk
android/app/build/outputs/apk/slim/debug/app-slim-debug.apk
android/app/build/outputs/apk/full/release/app-full-release-unsigned.apk
android/app/build/outputs/apk/slim/release/app-slim-release-unsigned.apk
```

## 体积验收

- Full Debug：312.13 MiB；
- Full Release（本机 debug-key 签名）：286.28 MiB；
- Slim Debug：170.05 MiB；
- Slim Release（本机 debug-key 签名）：147.70 MiB。

Slim Release 比 Full Release 小约 138.58 MiB。裁剪来源是 Kokoro 的模型、
音色表、词典和发音规则；ASR、MNN、Local Dream、界面和业务代码均保留。
