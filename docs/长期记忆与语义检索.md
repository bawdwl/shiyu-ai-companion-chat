# 长期记忆与 Qwen 语义检索

## 1. 记忆分层

拾语的长期记忆不是单一向量库。当前实现分为：

- 近期原始对话；
- 结构化长期事实；
- 旧对话摘录；
- 共同事件和约定；
- 用户边界；
- 可选 Qwen 语义向量。

## 2. 结构化记忆

每条记忆包含：

- `subject`：用户、角色或共同；
- `fact_key`：稳定主题键；
- `value`：结构化值；
- `content`：自然语言内容；
- `kind`：用户报告、角色自述、共同事件等；
- `fact_type`：事实、偏好、计划、假设、观点、事件或角色自述；
- `epistemic_status`：明确、不确定、推断或争议；
- `source_authority`：用户明确、共同经历、角色自述或模型推断；
- 来源消息 ID 和逐字证据；
- 生命周期状态、版本关系和访问信息。

## 3. 写入原则

- 只记录原文明确支持的内容；
- 计划不能写成已经发生；
- 假设和观点不能写成确定事实；
- 角色即兴自述不能覆盖正式角色卡；
- 明确更正会创建新版本；
- 无长期价值的寒暄和重复内容被忽略。

## 4. 检索

### FTS4

Android 将中文文本切成单字、双字和三字 token，通过 FTS4 进行词法召回。该路径不依赖
外部模型，是默认和最终回退路径。

### 词法排序

在 FTS4 之外，系统还计算：

- 查询与记忆的词面重合；
- 完整短语命中；
- 核心用户资料；
- 钉住事实；
- 近期程度；
- 重要性和来源可信度；
- 计划、历史值和时间状态。

### Qwen embedding

安装 `Qwen3-Embedding-0.6B-ONNX INT8` 后：

1. 查询文本生成 instruction 前缀；
2. 模型输出 1024 维归一化向量；
3. 对当前记忆候选计算 cosine 分数；
4. 语义分数与 FTS4 和词法分数融合；
5. 返回最终记忆候选。

用户可以在“设置 → 语义”中关闭语义召回。关闭后即使模型已安装也只使用 FTS4。

## 5. 语义检索检测

“检测语义检索”会检查：

- 模型是否能加载并完成推理；
- 当前模型版本是否已有记忆向量；
- 选择一个有长期记忆的角色进行抽样；
- 检查抽样查询是否返回有效语义分数。

如果失败，界面会区分：

- 没有安装模型；
- 模型可推理但没有索引；
- 没有长期记忆可抽样；
- 有索引但向量检索没有返回分数。

## 6. 模型位置

云端包 `com.shiyu.chat.cloud` 的默认安装目录：

```text
/storage/emulated/0/Android/data/com.shiyu.chat.cloud/files/embedding-models/qwen3-embedding-0.6b-int8-v1/
```

外部存储不可用时回退到内部 App 目录。模型不进入 APK，卸载应用会删除模型。

## 7. 用户控制

用户可以：

- 查看记忆来源和证据；
- 校正内容；
- 钉住重要事实；
- 标为过时；
- 忽略下一轮；
- 删除记忆；
- 删除模型和全部向量索引。

## 8. 回退与安全

- 模型缺失、索引为空或加载失败时使用 FTS4；
- 向量带有内容哈希，记忆变化后旧向量失效；
- 检索结果始终限制在当前角色内；
- 记忆和世界书都是低权限资料，不是系统指令；
- 用户当前消息中的明确更正优先于旧记忆。
