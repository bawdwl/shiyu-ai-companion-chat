# 拾语 Android 0.19.0

本版本同时提供完整版和云端精简版，两个包共用同一套 8 个初始角色、头像和
聊天背景：宋知意、裴既明、李白、萧承渊、姜拂衣、空条承太郎、凌清鸢和沈砚辞。

## 主要变化

- 新增云端精简版 `com.shiyu.chat.cloud`，可与完整版同时安装，数据独立。
- 云端版移除 MNN、QNN、Local Dream、本地 ASR、本地 TTS 及相关原生运行库。
- 两个版本统一使用从作者本地云端版导出的 8 个角色档案和对应图片。
- 升级时同步默认角色，并清理旧版中不属于当前初始角色库的默认角色；
  用户自建角色不会被这段迁移删除。
- 角色管理页和消息页使用更小的头像缩略图、独立缩略图缓存、受限并发解码和
  更低成本的绘制方式，改善快速滑动时的卡顿。
- 宋知意和裴既明的固定训练 Prompt 未修改。

## 功能范围

- 完整版：云端聊天与角色生成、长期记忆、内部状态、场景、千问生图、本地 MNN、
  Local Dream/QNN、本地 ASR 和角色朗读。
- 云端版：云端聊天与角色生成、长期记忆、内部状态、场景、图片输入和千问生图。

## 验证

- 完整版与云端版各 94 项 JVM 测试通过。
- 两个 flavor 的 Debug Lint 和 APK 构建通过。
- 两个包均在手机上执行 `adb install -r -d` 覆盖安装，未清除用户数据。
- 升级后两个包均确认只保留上述 8 个默认角色，角色头像和背景路径有效。
- 聊天数据库、API Key、个人图片和录音不包含在发布包中。
