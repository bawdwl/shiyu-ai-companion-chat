# 拾语 Android 0.19.1

本版本集中修复 Android 页面切换和聊天布局问题。

## 主要变化

- 底部栏五个页面提前组合；点击首页、角色、设置等页签时直接切换，不再等待目标
  页面首次创建，也不再经过“先改状态、再触发翻页”的额外一帧。
- 首页角色预览和当前角色共用相同的固定高度输入栏。纵向切换角色完成时，输入框、
  最新角色消息和简介卡不再发生高度变化或向下跳动。
- `自由输入…` 占位文字从首帧就在输入栏内垂直居中，切换角色时不再先偏上再下落。
- 聊天上栏角色姓名下只保留角色标签，移除 MNN/云端 API 和“唯一对话”文字。

## 验证

- Android 完整版与云端版各 106 项 JVM 测试。
- Android Debug Lint 通过。
- 完整版与云端版 APK 构建及签名校验通过。
