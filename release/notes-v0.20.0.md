# 拾语 Android 0.20.0

本版本集中完善长期使用能力：

- 完整 ZIP 备份、校验、恢复与自动回滚保护；默认排除 API Key、模型权重和缓存。
- 脱敏诊断导出与“数据与安全”设置页。
- 最近消息分页加载；模型请求和后台记忆任务不再读取全部历史。
- 结构化记忆证据展示，以及纠正、钉住、标为过时、本轮忽略和删除。
- 保留式重答与回复版本切换；只有当前版本进入后续上下文和记忆提取。
- 从任意消息创建分支检查点，并恢复对应聊天、事件、场景和记忆。
- Prompt Inspector 分区估算、世界书 AND/OR/NOT、Inclusion Group、Sticky/Cooldown 和命中测试。
- 用户 Persona 设置。
