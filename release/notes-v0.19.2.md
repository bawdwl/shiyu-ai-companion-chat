# 拾语 Android 0.19.2

本版本修复 `0.19.1` 中输入框固定高度导致多行文字不可见的问题。

## 主要变化

- 空输入框继续保持 54dp 的稳定最小高度，切换角色时布局不跳动。
- 输入超过一行后，输入框会在 106dp 上限内自动增高。
- 超过最大高度后，输入框内部继续滚动，不再只显示最后一行。
- `自由输入…` 占位文字在折叠高度下保持垂直居中。
- 角色切换、底部栏切换和聊天上栏修复继续保留。

## 验证

- Android 完整版与云端版各 106 项 JVM 测试。
- Android Debug Lint 通过。
- 完整版与云端版 APK 构建及签名校验通过。
