# 拾语 Android 0.20.1

`0.20.1` 是 `0.20.0` 的数据一致性与稳定性修复版本，不新增大型功能。

- 切换分支前自动保存当前对话，并标记当前活动分支。
- 分支切换、回滚、消息编辑、回复版本切换和重答会递增会话 epoch；旧后台记忆结果不得写入新会话。
- 编辑较早用户消息或切换较早回复版本时要求先创建分支。
- 修改消息或切换回复后，相关结构化事实、摘录和事件会失效，避免旧事实继续污染后续回答。
- 相册图片在发送时复制到应用托管目录，历史外部图片在启动时尽量迁移；备份包含聊天托管图片。
- 数据库导出优先使用 `VACUUM INTO`，失败时保留 WAL checkpoint 复制兼容路径。
- 修复 Sticky 自我续期、NOT 关键词优先级和分支切换后的世界书激活状态。
- 人工纠正记忆保留旧值与纠正原因；本轮忽略会同时排除同源摘要和事件。
- 未确认固定事实不进入正式 Prompt。
- Prompt Inspector 明确标注估算值并显示记忆选择原因。
