Android 0.18.23 更新了角色体验、场景状态、事件记忆、图片裁剪和启动图标。

- 增加版本化角色上下文、确定性对话策略、记忆需求判断、事件记忆、当前回合情绪和场景状态。
- 首页角色切换不再被最新消息区域抢占滑动；展开历史时暂时暂停角色翻页。
- Local Dream 保留方形原图，由用户先选择 9:16 背景，再从背景中裁剪 1:1 头像。
- 移除启动图标的黑角背景，消除 Android 12 启动时的黑色闪屏。
- 撤回实验性的新角色 `image_composition` 生图规则，恢复此前已验证的英文外观提示词生成。
- 宋知意和裴既明继续使用与 LoRA 训练一致的精简固定 Prompt。

验证：307 项 Python 测试、89 项 Android JVM 测试、40 项前端状态测试、
React 生产构建、`assembleDebug` 和 `lintDebug` 通过。本次构建时没有连接
ADB 设备，因此 0.18.23 尚未执行本轮真机覆盖安装。
