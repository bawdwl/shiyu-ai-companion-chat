# 拾语 Android 0.19.3

本版本把普通角色聊天的内部状态策略收敛为单一的 `off` 行为。

## 主要变化

- 使用同一角色设定、同一 Prompt、同一 OpenCode `deepseek-v4.1-flash` 和 8 轮
  固定场景，对比 `off`、`lightweight`、`legacy` 三种策略。
- 场景覆盖计划与回忆、冲突、修复、无关闲聊、冲突再回忆、用户边界和称呼检查。
- `off` 稳定保住面试时间地点、冲突原因、修复语义和用户称呼边界。
- `lightweight` 接近 `off`，但没有稳定可见增益；`legacy` 增加完整状态注入，
  没有改善同一组检查，并可能把过时关系判断带进当前轮。
- PC 和 Android 删除三种模式选择，普通聊天不再注入持久心情、熟悉度、信任度、
  温暖度或关系阶段。
- 用户明确边界、本轮即时反应、长期记忆和相关事件继续生效。
- 旧状态表和历史数值保留，不执行数据删除；固定训练 Prompt 角色不受影响。
