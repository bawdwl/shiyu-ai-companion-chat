# 拾语 PC 设计系统

> 本文件是拾语 PC 网页版和 Windows 桌面版的视觉源文件。页面级规则位于
> `pages/`，存在时覆盖本文件。

## 设计方向

**记忆档案馆式角色陪伴工作台。**

界面把长期陪伴理解为一段被认真保存的经历：角色不是商品卡片，记忆不是后台
表格，聊天也不是电商客服窗口。主界面采用熟悉的三栏工作台，人物图像负责建立
情感连接，墨绿和米纸负责提供稳定的阅读环境。

- 产品类型：AI 虚拟角色陪伴、即时聊天、长期记忆。
- 桌面优先，支持 375、768、1024、1440 和 1920px。
- 默认浅色；深色模式作为后续独立主题，不与浅色规则混用。
- 用户进入聊天后应先看到角色、消息和输入框，而不是营销区块或设置面板。

## 色彩

| 角色 | 色值 | 用途 |
|---|---|---|
| 墨绿 | `#123E30` | 主导航、沉浸背景 |
| 叶绿 | `#1F6049` | 主要操作、选中状态 |
| 米纸 | `#F4F1E8` | 主背景 |
| 纸白 | `#FFFDF8` | 输入框和可读表面 |
| 旧金 | `#E5CFA9` | 少量强调和焦点 |
| 梅紫 | `#815B68` | 次级点缀，不用于大面积背景 |
| 正文墨 | `#20241F` | 主要文字 |
| 静默灰 | `#70746D` | 次级文字 |

禁止使用高饱和紫粉渐变、满屏玻璃拟态、霓虹发光按钮和无语义装饰光球。

## 字体

- 中文正文：Microsoft YaHei UI、PingFang SC、Noto Sans CJK SC。
- 中文标题：Songti SC、STKaiti，仅用于品牌和章节标题。
- 英文小型标识：与正文同一字体，不使用全大写英文装饰标签。
- 正文最小 14px；辅助文字不小于 11px；标题使用 20/27/40px 层级。

## 间距与形状

- 4px 基础节奏，常用 8、12、16、24、32、48px。
- 聊天输入框圆角 18px；普通控件 10–12px；人物面板不做通栏大圆角卡片。
- 阴影只用于浮层、输入框和当前选中层级，不对所有卡片统一套阴影。
- 动效只使用 transform 与 opacity，时长 150–240ms，并遵守
  `prefers-reduced-motion`。

## 桌面布局

```text
┌──────────────┬────────────────────────────┬──────────────────┐
│ 导航 / 角色   │ 对话 / 阅读                 │ 角色 / 记忆       │
│ 236px        │ minmax(0, 1fr)             │ 312px            │
└──────────────┴────────────────────────────┴──────────────────┘
```

- 小于 1180px：右侧角色栏变为可收起抽屉。
- 小于 900px：左侧导航缩窄；聊天动作改为图标按钮并隐藏低频入口。
- 小于 760px：左侧导航变为 62px 顶部栏，角色信息与创建/设置保持可访问。
- 消息区是唯一纵向滚动区域，顶部栏和输入区不得被页面滚动带走。

## 组件规则

- 主按钮使用叶绿底白字；次按钮使用纸白底和可见边框。
- 破坏性操作使用语义危险色，并与主操作保持空间距离。
- 人物图使用真实的 `width`、`height` 和 `object-fit` 预留空间。
- 图标使用项目内统一 SVG 线性图标；图标按钮必须有 `aria-label`。
- 模态框必须支持 Escape、焦点循环、关闭后恢复触发点。
- 所有异步状态通过 `role="status"` 或明确的内联提示反馈。
